# ЗАВДАННЯ

## Застосунок
MiniShop — консольний Python-застосунок для ведення одного списку покупок із локальним збереженням у JSON.

Функції: додавання, перегляд, зміна статусу, видалення, збереження, завантаження та фільтрація товарів.

Технології: Python 3, JSON, pytest.

Повні вимоги: docs/app-requirements.md.

## Агентна IDE
Codex у VS Code.

## Мета Agent Harness
Забезпечити контрольовану, відтворювану розробку застосунку за допомогою AI-агента.

## Цільові задачі агента
1. Генерація програмного коду.
2. Генерація автоматизованих тестів.
3. Перевірка якості коду.
4. Оновлення документації та бази знань.

## Обмеження
Дотримуватися вимог проєкту та правил Agent Harness.

Повні вимоги: docs/harness-requirements.md.

База знань Obsidian зберігається в окремому репозиторії MiniShop-KB.
